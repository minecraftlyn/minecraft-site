About Minecraft LYN

A community-focused platform for Minecraft Bedrock resources.

What is Minecraft LYN?

Minecraft LYN is a dedicated resource platform created for Minecraft Bedrock Edition players. Our goal is to make it easier for players to discover, explore and download useful and interesting Bedrock resources from one clean and simple website.

What can you find here?

The website is designed to collect different types of Minecraft Bedrock resources, including Addons, Shaders, Maps and other community-made content. Each resource can have its own cover image, description, supported Minecraft versions, creator information, file format, file size, features, screenshots, version history and direct download link.

Built for Bedrock players

Minecraft LYN focuses mainly on Bedrock / MCPE users, especially mobile players. The website is designed to work comfortably on phones while still providing a useful experience on tablets and desktop browsers.

Simple discovery

Instead of searching through many different pages, visitors can use categories and search to quickly find the type of resource they want. Resources can also be saved locally in the browser so they can be found again later on the same device.

Our goal

Minecraft LYN is being developed as a growing resource hub. We want to continue improving the website, adding more resources, improving download information and making navigation faster and easier for the community.

Important note

Minecraft LYN is an independent community project and is not affiliated with Mojang Studios or Microsoft. Resource ownership and creator rights remain with their respective creators. Please respect the original creators and their download terms.
